The process

How it's built.

Same rhythm every engagement — clear phases, weekly demos, written deliverables. Nothing is "in review" forever.

01
Audit

Map every event, every tool, every dashboard. Find the duplicates, the misses, the broken stuff. You leave with a written assessment.

02
Spec

Design a clean event taxonomy. Naming conventions. Who fires what, when, with which properties. This is the document your team will reference for years.

03
Implement

Server-side first. Client-side as backup. Test events fire correctly across browsers, ad-blockers, and platforms. Validate against the spec.

04
Train

Your analytics team learns the taxonomy. Your engineers learn to add events without breaking it. Dashboards rebuilt against the new foundation.

Common questions

Before you ask.

Do we need a warehouse?+

Eventually, yes. Even if you're not using one today, I'll set up the pipeline so it lands somewhere queryable. BigQuery is free for the first terabyte — there's no reason not to.

What about privacy / GDPR?+

The CMP layer is part of the implementation, not an afterthought. Consent-mode handled correctly so you stay compliant without losing the signal.

Can you fix tracking without ripping it out?+

Sometimes — but in 80% of audits, the existing setup has accumulated enough drift that a clean rebuild is faster than patching. I'll tell you honestly.
